# Desktop Experience

Desktop supports operational work plus administration and dense review.

## Home
Use an action-oriented workspace inspired by strong modern SaaS hierarchy rather than a generic admin template:
- Needs Attention
- Asset health summary
- recent activity
- useful shortcuts/search
- role-aware modules

## Inventory
Desktop may offer table and visual/card modes. Tables are useful for scanning and export-oriented workflows, but image/context should remain accessible.

## Requests
Support request queues, filtering, approval/review, and request detail.

## Master Data
Desktop is the preferred environment for:
- brand/category maintenance;
- warehouse/vendor maintenance;
- division;
- user mapping;
- approval matrix.

## Reports
Support operational listings and useful breakdowns. Do not invent financial analytics.
