# UI Reference Direction

## Desired qualities
- Clear modern SaaS hierarchy
- Action-oriented home
- Strong whitespace and typography
- Calm surfaces rather than excessive card chrome
- Image-aware asset browsing
- Mobile-first operational speed
- Refined, non-generic component composition

## Reference interpretation
The supplied modern SaaS dashboard reference is useful for:
- greeting + contextual home hierarchy;
- “things to do” / attention-first pattern;
- restrained sidebar structure on desktop;
- clean grouping without dashboard clutter.

Do not copy its branding, exact colors, or HR-specific content.

## Avoid
- default shadcn demo appearance;
- generic admin dashboard with many equal KPI cards;
- desktop sidebar merely hidden behind a hamburger without redesign;
- excessive gradients;
- arbitrary icons everywhere;
- dense forms on mobile;
- decorative charts without an operational decision.
